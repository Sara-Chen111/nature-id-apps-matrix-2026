## 数据口径（先读这个）

- 样本 = 108 款美区识别类 App（植物 43 / 鸟 20 / 鱼·钓鱼 13 / 岩矿 11 / 综合 7 / 昆虫 7 / 真菌 7）。
- **下载 / 收入四个指标**（最近30天 / 最近4年 × 下载 / 收入）按 10 倍一级分 7 档（1K以下 … 1亿+，收入另单列免费 App）：
  - **有七麦（Qimai）估算的款：下载 80 / 收入 70**：七麦 iPhone 估算 × 校准系数（收入 0.267、下载 1.394，以点点数据为基准拟合），悬浮卡显示校准后的**估算数值**（≈ 开头，万 / 亿单位）；数字按点点档位区间夹逼。**这是估算值，不是财务数据**。
  - 其余款（收入 38 / 下载 28）：用点点档位、按**档位下限**归档（悬浮卡标「下限」），一档跨 100 倍，真实值可能高一级。
- 评分、评分数、价格、Android 安装与 Play 评分 = 商店页快照（2026-11-02）；下载收入抓取 2026-11-07。
- 功能位 = 商店描述「宣称具备」，不等于实测可用；「官方怎么证明认得准」= 商店描述原句 + 科研机构关系 + 实拍截图，自报准确率都是厂商宣称。
- 评分数 ≠ 下载量 ≠ 评论数；10 倍一级只看量级。
